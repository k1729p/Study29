### Notes
Vector databases are storage systems specially designed to store high-dimensional vectors.

An embedding is a numerical value that represents some unstructured data.
A machine learning model assigns vector embeddings during training.
These values are expressed as n-dimensional vectors, with each dimension representing a data property.

Search Methods
- semantic search: aims to query data within a given context to return relevant results
- full-text search: involves searching through the entire document to find matches for a query

Unlike traditional DBs, Vector DBs are often queried via API methods or Similarity Search functions
rather than a standalone string-based language.
